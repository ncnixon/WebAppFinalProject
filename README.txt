Variable names for referencing user-specific info:
note: seperated by required and not required.
* = will be implimented as an array so can have multiple values



required fields (gauranteed to exist):
    user.username = their @ style name to reference that specific user. No 2 alike.
    user.display_name = their chosen display name. Can be the same as someone else
    user.birthday =  birthday. style is  mon. dd, yyyy


not required fields (not gauranteed to exist):
    user.email = thier input email. currently this is not a required field. 
    user.year = fresh, soph, jr. or sr.
    user.major_type*  = AA, AS, BA, BS, MA, MS, etc
    user.major* = Bachelor's of forestry, Masters of comp sci, etc.
    user.minor* = poly sci, graphic design, etc.
    user.certificate* = welding, MRI tech, etc.
    user.interests* = reading, gaming, fishing, etc.
    user.bio = string with the bio they put in. 
    user.friends* = array with list of usernames that have been mutually accepted as friends
